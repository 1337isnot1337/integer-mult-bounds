# Owned center COPY-chart retiming

Exploratory, source-bound model. No new supplier or kappa is established.
The ongoing bounded scan and its limits are recorded in [TASK.json](TASK.json).

The previous common-kernel contact model freezes every owned contact and pays
eight rank-eight center jobs as constants. This experiment releases the eight
actual COPY input charts. Each COPY still shares one chart with its actual
persistent source. The owned stream starts from an explicit CLEAR, is copied,
returns to the unchanged zero chart through its paid center transform, serves
every original scatter consumer, and is cleared again. COPY sources, scalar
order and coefficients, native maps and all main endpoints stay fixed.

The changed center job is charged at its actual canonical-frame Fourier rank.
For one nonzero kernel functional its rank is seven or eight. Every ordinary
non-nested bridge and changed native warp remains in the full paid invoice.
All 408 independent arbitrary-input helper jobs are retained; the owned center
earns no productive credit. Three COPY sources happen to be productive helpers,
which does not create additional target jobs.

`discover.py` imports the unchanged exact-rank graph and signed-cut solver from
`general-gaussian-contact-search`, authenticates the pinned sources before
import, reconstructs all eight actual chronological COPY/center lifetimes,
and replaces the fixed center charges with their actual switch tables. The
all-zero model must reproduce both complete source histograms exactly:

* paid: `{1:2201,2:412,3:510,4:127,5:40,8:8}`;
* helpers: `{4:28,7:7,8:47,9:326}`.

Optional discovery uses NumPy 2.5.4 and SciPy 1.18.1:

```sh
python3 -B research/owned-centre-kernel-retiming/discover.py --start 1 --end 511 --seconds 5
```

It checkpoints each completed case in `SEARCH-1-511.json` and stops at the first
floating candidate with a complete negative paid-minus-helper moment delta.
Solver status and a zero objective do not prove a universal obstruction.
Even a strictly negative floating delta is only a candidate, pending exact
moment inequalities, emitted word, arbitrary-input operator and absolute-phase
replays, and funded compiler/precision/outer admission.

`calibrate.py` is a separate small physical check using the actual nine-axis
Clifford implementation. It lowers the center and every incident persistent
bridge when each COPY contact is changed individually at functional 1, with
both monomial adapters and absolute phase. This deliberately costly local move
checks the rank accounting; it is not a profitable supplier. Its execution
status belongs in the checkpoint/receipt, not an assumption of this README.
Run it after the discovery scan has stopped, so the two artifact-generating
commands do not overlap in this worktree.

## Open next questions

If a candidate appears, first reconstruct its literal CLEAR/COPY/center/scatter
sequence and certify the full paid/helper moment exactly. The Gaussian work
must not return as an omitted persistent conversion or cleanup.

If the bounded scan finds none, stop this common-kernel model. Independent
contact subspaces coupled to changed shared native maps are a different model;
an expansion needs its own full boundary/cost ledger and bounded decision. No
favourable profile for that larger model has been established here.
