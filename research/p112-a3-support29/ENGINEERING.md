# Verification design

The exit predicate is one source-bound new lemma or counterexample with
reviewable evidence, followed by publication and a clean reusable worker.
The accepted unit is the sharp support29 theorem and literal support30
witness. No new historical profile application is counted.

Build the Lever shaped the artifact: model.py and the registered verifier
make every finite premise and witness rerunnable. Prove It Works shaped
the evidence: actual rational witness ranks, literal code identities,
separate lattice/subset/frame algorithms and semantic rejection controls
replace inference from a passing import. Prose was edited with unslop.

Power of Ten inspection: traversals have finite input-derived bounds;
no recursion or process spawning is used. Frame DFS visits at most
400,000 nodes, holds at most 1,000 pending nodes and returns 2,025 frames.
Independent traversal has eight levels and at most 200,000 entries per level.
RREF free bits are at most eighteen, labels are nine-bit, and binary spans
have at most 512 entries. Matrix elimination has at most 42 rows and
112 columns. Defect feasibility uses five frame types and five endpoint
counts. Functions are below sixty physical lines after formatting except
the cohesive witness boundary checker documented below.

Python allocation is a managed-runtime deviation from fixed allocation;
enumerated domains bound live storage. Fraction arithmetic and unchanged
source geometry retain their runtime allocation. The one dynamic module
load uses an explicit authenticated path, checked before execution. This
is a metaprogramming deviation with one fixed target. Exception exits
propagate failures; receipt writes use exclusive creation and context-managed
closure. Library return values are consumed except conventional in-place
collection/file writes whose results do not govern a proof. The witness
boundary checker spans 63 physical lines after formatting: it stays cohesive
so frame, support, code-identity and rank checks remain visible together.
This is a three-line deviation from the sixty-line function guideline.

The source geometry is unchanged and retains predecessor implementation
choices; no unrelated rewrite was made. Assertions do not enforce proof
checks: explicit ValueError checks remain active under optimization.
Fourteen behavioral groups exercise the valid witness, the boundary where
ten labels do not pin rank six, invalid budget domains and mutated source,
frame, small support, endpoint coefficients, support receipts and rank claims.

The primary checker recomputes inherited six-flat/parabolic/root-plane
premises. The separate checker independently reconstructs roots/labels and
checks the new robust subsets, frames, budgets and witness. It does not
independently repeat six-flat capacity, full singleton closure or Weyl/chamber
classification. Internal mathematical review corrected an initially omitted
(8,4) puncture class. Internal code review tightened witness rank receipt
fields. Neither review is independent human or proof-kernel review.
