# Actual repacked native rule: ownership, chronology, and compilation

The complete native packing has an executable rule with all 2,242 actual
productive field names and all 25,292 chronological paid calls. Its
rank-57 completion has `B_57=2242` and `P_57=127570`, including every
source complement. Its owned center is charged and remains uncredited.

This integration is separate from the [native endpoint proof](README.md).
It authenticates that proof's producer and receipt, reconstructs the exact
derived cover, and checks the cover's digest. It then independently
extracts the actual main endpoints, fresh fields, local stage order, and
paid-call owners from the original pinned native sources. The resulting
paid word must agree with the native receipt's chronological digest.

## Idle lifetimes and physical composition

The changed wide windows belong to physical pair 1. In the pinned formal
controller, their stages 0 and 1 are adjacent local calls on pair 0;
stages 5 and 6 are adjacent local calls on pair 2. Each pair of local calls
is followed by the relevant complete `IDLE` before the next scalar bridge
or signed swap. The borrowed pair is therefore inactive while either
changed window is partially complete.

The integration checks all 896 windows against the exact formal event
word. Every hosted call precedes its window's completion. No intervening
local call, scalar ADD, or signed swap reads or writes the borrowed pair.
The physical owner name is checked against that pair, side, and port.
A control inserts a bridge reading an incomplete initial-window field;
the lifetime check rejects it.

The native packing proof separately checks that each new `(6,9,1)` or
`(9,6,1)` partition covers the unchanged 16 axes exactly once and retains
the original translation. Its whole-helper conjugations use complete
57-dimensional invertible address maps and the actual oriented native
normalizers, including absolute phase. The autonomous endpoint identity
applies to each arbitrary borrowed field and all spectators. Therefore
the complete window is restored before any external controller use.
The new coordinate maps have their own finite movement constants.

## A complete actual rule

All 672 main field names and all 1,570 new fresh names are reconstructed.
The fresh set changes when different native roles are hosted in the idle
windows. The integration records exactly which fresh names disappear and
which appear. It rejects using the prior fresh owner contract with the
new paid word.

At every local stage, all 408 native helper roles have distinct physical
owners, disjoint from the active main pair. Paid climbs are attributed to
the actual X, Y, or helper owner; each center event stays on `owned-C0`.
Every residual call is appended in its original chronological stage.
The source and paid histograms must be precisely the new native profile.

The new `WeakRule` accepts this complete named contract. The original
strict constructor rejects it, because its maximum paid rank and minimum
target rank both equal five. The imported `IntegerTree` and `Compiler`
remain the authenticated original implementations.

At ambient rank 57, the integration materializes one native unit,
25,292 separate ordered exit batches, and 50,586 event nodes. Every exit
is checked against its exact native round index, rank, and actual field.
The graph is acyclic, all independent input fields are distinct, and
every chronological batch separately clears its denominator. The source
profile is `{5:140,6:52,7:56,8:93,9:1229,25:448,57:224}`.

## Reproduction and scope

```sh
python3 -B research/kappa-4359-native-packing/compiler_check.py --source-root /path/to/pr4359 --check
```

This authenticates the source and compares the deterministic result with
[COMPILER.json](COMPILER.json). Use `--out /tmp/packing-compiler.json` to
write a separate receipt. No previous proof or certificate is modified.

This actual-native integration has generation depth zero. The separate
weak compiler package exercises equality cases through four generations.
The stronger mixed exponent requires the new weighted-tail proof and
adequate large fixed template; it does not follow from the rank-57 test.
The endpoint, all-column, native movement, precision, and outer analytic
premises retain their stated conditional scope.

New material is Apache-2.0. The actual native word and frozen compiler
come from PR #4359 at `da637c87c89482bc4c86be36bd0071b3d400dbed`;
the underlying mixed integer flow retains the predecessor's attribution
to Jacob Alan Sussman's PR #4268.
