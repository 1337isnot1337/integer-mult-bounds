### Why the 14 byte differences are accepted

The comparator does not waive arbitrary changed fields. It removes only
its declared timing keys, checks three explicitly permitted environment
metadata locations against the actual runtime, and substitutes exact
old-to-fresh hashes for the 59 reconstructed scientific artifacts.
All remaining scientific content agrees. The retained receipt records
the actual runtime metadata and all old and new artifact hashes.

The four controls alter the target kappa, make a functional gap negative,
insert an undeclared environment field, or falsify permitted fresh-host
metadata. The comparator rejects every case. The control runner restores
the original fresh artifacts and repeats the positive comparison.
These are specific discrimination checks; they do not make arbitrary
changes to the checker or its executable dependencies trustworthy.

## Additional multilevel census

The native examples in the original materialized compiler test use a
zero-generation flow. `count_multilevel.py` adds an independent count
model for deeper native flows. It enumerates target exponent compositions
with exact multinomial weights, groups ordered paid paths by their common
dilation, cancels internal jobs, and records the remaining sources and
deepest exits. All counts are integers.

The test authenticates its three source inputs against fixed SHA-256
values. Its count implementation is separate from the original
`IntegerTree`. Six small complete trees cross-check its source census,
exit census, unit count, and full normalized paid-leaf recurrence against
the frozen explicit compiler.

For both actual native tariffs it then checks generation depths 0, 1, 2,
and 3:

| Family | Tested ranks | Exact recurrence evaluated |
| --- | --- | --- |
| Complex p3 | 57, 342, 2052, 12312 | Ranks 57 and 342 |
| BIT | 50, 400, 3200, 25600 | Ranks 50 and 400 |

Every source has rank in `(n/m,n]`, every exit has rank below `n`, and
the exact identity

```math
\sum_s N_s s-\sum_e N_e e
=\left(\sum_k W_k k-\sum_j r_j\right)
  \sum_{\text{units }u}\operatorname{columns}(u)
```

holds. The recurrence includes the complementary job for every source
array as well as every exit job. A control that adds one unearned source
breaks the independently computed conservation identity.

The deeper cases make the scale concrete: the complex rank-342 flow has
25,586 native units and 644,855,236 exit jobs. Grouping identical counts
allows exact arithmetic without materializing those fields. Accordingly,
this check certifies aggregate integer accounting. It does not claim to
materialize a native graph with positive generation depth or independently
prove its physical ownership and chronological scheduling.

## Composition review

The source proof uses complete productive jobs on arbitrary inputs. A
source complement and every paid exit remain in the normalized recurrence.
Owned center fields have actual lifetimes and may be inputs to a child
invocation; they are never counted as productive outputs. The compiler
clears denominators for each chronological batch separately, so a later
child batch cannot silently fund an earlier suspended round.

The native endpoint review checks the distinction between scalar linear
combinations of decoded role arrays and products of physical operators.
The symbolic checker uses reduced words in invertible noncommuting
generators, with cancellation only of adjacent inverse pairs. Therefore
its identity survives assigning each generator its actual column lift.
No tensor-power identity for a sum of operators is used. The phase of a
rank-zero normalizer includes the required constant `a*f`, and the BIT
argument retains the premise that the common external weight is
independent of every fresh cover field. The separate lift note gives
the reasoning and its limits.

## Reproduction

Run from the contribution checkout, with a separate pinned predecessor
checkout at `/path/to/pr4359`. The contribution does not duplicate the
predecessor's imported source tree. Use the exact reviewed head named
above; the count verifier authenticates its required source bytes.

```sh
python3 -B /path/to/pr4359/research/kappa-0023-productive-jobs/verify.py --check-only
python3 -B /path/to/pr4359/research/kappa-0023-productive-jobs/verify.py --out /tmp/pr4359-fresh-replay
python3 -B /path/to/pr4359/research/kappa-0023-productive-jobs/check_comparison.py --repo /tmp/pr4359-fresh-replay/repo --report /tmp/pr4359-comparison-controls.json
python3 -B research/kappa-4359-audit/count_multilevel.py --source-root /path/to/pr4359
```

Choose an unused output directory for the fresh replay. The last command
recomputes and compares the deterministic committed count certificate.
Pass `--out /tmp/pr4359-counts.json` to emit a separate fresh copy.
Only source-relative paths enter the deterministic count receipt, so
the predecessor checkout location does not affect its bytes.
