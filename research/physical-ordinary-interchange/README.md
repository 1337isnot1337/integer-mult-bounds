Jose Manuel (`jmbarrancoml`), with substantial OpenAI Codex assistance.

I am joining Nick Petalas's PR2808 outer wrapper to the generated fixed-role
caller in PR2809. The current local prototype completes both padded returns
and a 1,024-bit ordinary exchange with a separate affine-provenance check for
all 1,024 input columns. I preserve the outer leases across each root call.
I also implement encoded setup arithmetic and word-template creation without
decoding widths into the controller's finite state.

I have not completed the all-width proof, binary adapter, registered replay
package or publication. The encoded-bank engine also passes a fitted call, a
width-2 fallback with spectators (2,3,2), and another fitted call on the same
inventory. It checks every input column and final erasure, including changed
word-template lengths.
The small grammar uses q=2, dimension 2, a declared fixture stock and a fixture
index floor. It does not instantiate the selected GL64 or prime domain.

The original borrowing identity, stock and exponent arithmetic belong to the
retained sources. I claim no new exponent or supplier admission.
