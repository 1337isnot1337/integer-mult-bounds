## Exact findings

Independently enumerate the GF(2) nullspaces of all 636 source-frame annihilator
matrices. Apply kernel150's quotient and the proposed full-image re-padding.
The independently reconstructed boundary dimensions agree with every boundary
in the frozen PR artifact, including all439 width-eight helpers.

For the111 paired main fields, the two diagonal transport widths are:

    (X,Y) = (7,6) on101 pairs; (8,6) on6 pairs; (7,8) on4 pairs.

Thus every pair has unequal widths. This is not merely a change in frame names.
The existing physical BIT controller in mixed_productive_bit.py explicitly
uses D_Bs on BOTH members of each pair, where B_s is the same rank-seven block.
Its local() routine shifts both diagonal rows by the same stage generator.
The quotient artifact's own logical-column replay does not check this physical
common-stage identity and does not derive a replacement controller.

The same independent enumeration checks all255 one-dimensional kernels.
Every Y main has width6 or8 after this particular quotient/re-padding rule,
never the required width7. Changing the kernel therefore does not by itself
restore the unchanged width-seven consumer. This statement does not rule out a
new consumer or a re-synthesized supplier.

## An optimistic append-only repair already loses

Keep the quotient word, helpers, and existing width-seven controller invoice.
Repair each independent main output by appended paid Gaussian transforms, with
no re-synthesis, fusion into earlier calls, or changed consumer. Each of the107
width-six and10 width-eight mains needs at least one positive-rank correction
to return to width seven. This grants the correction its best possible price:
117 rank-one jobs, ignoring additional chart, query, phase or ownership costs.
It is a lower bound only within this explicitly append-only repair model.

The resulting optimistic paid profile is

    {1:1315,2:1255,3:207,4:86,5:41,6:23,7:1}.

Its rank mass is5140, versus5129 for the original source word. More strongly,
its paid-minus-source capped moments sum(delta_r * min(r,k)), for k=1..7, are

    [8,24,127,102,35,29,11].

Every increasing discrete concave function on0..7 vanishing at0 is a
nonnegative combination of these capped functions. Therefore the repaired
paid moment is strictly worse than the predecessor for every exponent0<t<=1.
The source and repaired helper/target and other controller rows are unchanged.

Exact rational log/exp enclosures additionally evaluate the full p16 invoice.
At the PR's claimed kappa0.012401086416, the repaired paid-minus-target first
moment is approximately2106, strictly POSITIVE, so the necessary first-moment
inequality fails. It also fails at the source's reported0.003464248972, with a
positive gap approximately202.51. RESULT.json contains outward-rounded rational
micro-unit bounds, not floating-point acceptance tests.

## Final dimension-three revision: stronger append-only failure

The final head uses kernel basis[150,102,255]. Independent source-subspace
intersection calculations reproduce its222 main widths:103 width-four,
70 width-seven and49 width-eight. The retained helper widths are unchanged.
Even the optimistic independent append repair needs103 rank-three jobs and
49 rank-one jobs. Splitting such a correction cannot lower this concave cost.

After adding these to the supplied paid profile and retaining its p16 consumer,
ALL127 capped global paid-minus-target moments are strictly positive. Their
minimum is525, attained at cap127. By the same discrete-concavity expansion,
the repaired first moment fails for EVERY exponent0<t<=1, not just the
headline numerical value. This remains an append-only result, not a bound on
integrated re-synthesis or a new controller.

There is also a simple dimension obstruction for every nontrivial kernel K
of dimension k,1<=k<=7. Each original Y terminal H is a hyperplane. If K is
contained in H, its quotient image has dimension7-k. Otherwise the image has
full quotient dimension8-k, which this construction re-pads to8. Thus every Y
width is either7-k or8, never7. This argument applies to the stated full-image
re-padding rule and unchanged width-seven consumer, not every embedding rule.

## What follows, and what does not

The PR's stated local evidence does not establish its claimed outer0.0124.
The unchanged common-stage consumer needs an actual new interface proof or a
repair. This particular append-only repair cannot supply the claimed gain.
This is NOT a universal lower bound on quotient constructions, arbitrary
frame retiming, another physical caller, merging repairs with old calls,
productive correction outputs, or different analytic/compiler parameters.

Independently, a two-constraint floating-point local screen does not establish
all outer admission obligations. Changing literal admission constants is not
itself a proof of those obligations. This package does not audit every possible
replacement outer theorem, nor does it repeat the entire original local replay.
It checks the changed boundary dimensions, prices the append-only floor, and
binds the mismatch to the actual consumer source.
