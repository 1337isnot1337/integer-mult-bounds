## Construction

The augmented-center calculation in ../h-boundary-commutator records the exact
center response rows R and leakage columns U of the current full-identity word.
Its logical block map is (M l+U c, R l+c), with no cross-center feedback.
Deleting the eight center responses therefore changes the live map to M-UR.

In the backward orientation, the unwanted helper terms can be compensated at
input: the response reads only zero-frame Y inputs, and all affected helpers
start at frame zero. In the forward orientation, the unwanted terms read only
zero-frame helpers and affect zero-frame Y inputs. Eight short factored scalar
preconditions implement the compensation, reusing one cleared owned field.

After this compensation, the main kernel is the symmetric J and all 408 helpers
are clean. The inherited eight selected-row rank-one completions change J to H.
The backward completion is a prefix and the forward completion is a suffix;
H is not symmetric, so these orientations must be checked separately.

The existing eight rank-eight center queries are removed. Eight rank-one
completion queries are added. Every other recursive transport and all helper
boundaries are retained. This gives the exact profile above. New scalar
preconditions are physically at common frame zero, not merely equal logical
labels. Their full emitted word is in NATIVE.json.gz.
